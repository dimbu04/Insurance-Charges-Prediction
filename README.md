Insurance Charges Prediction using Snowflake ML and XGBoost
   This project builds an end-to-end machine learning workflow to predict insurance charges using the insurance dataset, XGBoost regression, Snowflake Model Registry, and a Streamlit dashboard.

Project Overview

Technologies Used: Snowflake, Snowpark ML, XGBoost, Python, Streamlit

Workflow: Data loading → preprocessing → model training → model registration → prediction → dashboard

Dashboard Features: Prediction history, summary metrics, chart, and manual prediction

How to Run: Basic setup and deployment instructions
